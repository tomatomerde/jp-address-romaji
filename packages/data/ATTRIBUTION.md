# Data attribution

The dataset generated by this package is derived from:

## Address Base Registry (アドレス・ベース・レジストリ)

Published by the **Digital Agency, Government of Japan**.

- https://www.digital.go.jp/policies/base_registry_address

The Address Base Registry is published under terms permitting free use, including
commercial use and redistribution. Confirm the current terms at the link above
before redistributing a generated dataset.

## Geolonia processing

The registry data is processed and served by **Geolonia Inc.**

- `@geolonia/japanese-addresses-v2` — MIT License
  https://github.com/geolonia/japanese-addresses-v2
- `@geolonia/normalize-japanese-addresses` — MIT License
  https://github.com/geolonia/normalize-japanese-addresses

Geolonia notes that the public API is offered without charge but without an
availability guarantee, and recommends hosting the data yourself for production
use. This package exists to do exactly that: the data is fetched once at build
time and read locally thereafter.
